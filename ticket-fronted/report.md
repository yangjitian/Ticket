# 票务管理系统项目报告

## 项目概述
票务管理系统是一个集景区管理、门票销售、订单管理、用户管理、分销商管理等功能于一体的综合性票务分销平台。系统支持多种用户角色（管理员、游客、分销商），提供完整的门票购买、支付、核销流程，以及数据分析和管理功能。

## 项目架构

### 技术栈

#### 后端技术栈
- **框架与开发语言**：Spring Boot 3.3.6 + Java 21
- **ORM框架**：MyBatis Plus Spring Boot 3 Starter 3.5.5
- **数据库**：MySQL 8.0+（mysql-connector-j）
- **缓存**：Redis（Spring Data Redis + Apache Commons Pool2）
- **认证与授权**：JWT（0.12.6）+ Spring AOP
- **API文档**：Knife4j（OpenAPI 3）
- **工具库**：Hutool（5.8.35）、Lombok（1.18.36）
- **邮件服务**：Spring Boot Starter Mail
- **对象存储**：腾讯云 COS（cos_api 5.6.213）
- **构建工具**：Maven 3.6+

#### 前端技术栈
- **框架与开发语言**：Vue 3.5.25 + TypeScript 5.9.0
- **UI组件库**：Element Plus 2.13.0
- **路由管理**：Vue Router 4.6.3
- **状态管理**：Pinia 3.0.4
- **HTTP客户端**：Axios 1.13.2
- **图表库**：ECharts 6.0.0
- **构建工具**：Vite 7.2.4
- **代码规范**：ESLint 9.39.1、Prettier 3.6.2
- **图标库**：@element-plus/icons-vue 2.3.2

### 中间件与依赖

#### 后端中间件
- **MySQL**：关系型数据库，存储系统所有业务数据
- **Redis**：内存缓存，用于会话存储、数据缓存、分布式锁等
- **Apache Commons Pool2**：对象池库，提供Redis连接池支持

#### 前端工具
- **Node.js**：JavaScript运行环境（要求^20.19.0或>=22.12.0）
- **npm**：包管理器（项目使用npm-run-all2进行脚本管理）

## 各模块详细功能说明

### 1. 架构与基础层
- **Spring Boot配置**：application.yml配置文件，包含数据源、Redis、邮件、COS等配置
- **AOP切面**：权限控制切面（RequireAdmin、RequireLogin注解），实现统一的权限验证
- **全局异常处理**：BusinessException、BaseResponse、ErrorCode，提供统一的异常处理和返回格式
- **工具类**：JwtUtils（JWT生成和验证）、OrderUtils（订单号生成）、UsernameGenerator（用户名生成）
- **定时任务**：ScheduledTaskConfig，支持定时执行任务

### 2. 用户管理
- **用户注册**：支持邮箱注册，发送验证邮件
- **用户登录**：支持邮箱/密码登录，JWT token认证
- **用户信息管理**：修改密码、修改个人信息、上传头像
- **用户角色管理**：管理员、游客、分销商角色控制
- **用户状态管理**：用户禁用/启用、分销商审核

### 3. 景区管理
- **景区信息维护**：新增、编辑、删除景区信息
- **景区图片管理**：景区图片上传（COS存储）、图片预览
- **景区搜索**：根据景区名称、省份、等级搜索
- **景区状态管理**：景区开放/关闭状态控制
- **景区详情展示**：景区介绍、开放时间、联系电话等信息展示

### 4. 门票产品管理
- **产品信息维护**：新增、编辑、删除门票产品
- **价格管理**：设置零售价格、结算价格、分销商销售价格
- **票种管理**：支持原价票、半价票、免票等票种
- **产品状态管理**：产品上架/下架状态控制
- **产品关联管理**：景区与门票产品的关联关系管理

### 5. 库存管理
- **库存查询**：查询景区每日库存信息
- **库存预警**：设置库存预警值，当库存不足时提醒
- **库存扣减**：购票时实时扣减库存
- **库存恢复**：订单取消或退款时恢复库存
- **批量库存更新**：支持批量设置景区库存

### 6. 订单管理
- **订单创建**：用户下单，生成订单
- **订单查询**：根据用户、日期、状态等条件查询订单
- **订单支付**：模拟支付功能
- **订单核销**：使用核销码验证门票
- **订单取消**：用户取消订单，恢复库存
- **订单退款**：处理退款申请
- **订单通知**：发送订单创建、支付、核销等通知邮件

### 7. 游客信息管理
- **游客信息维护**：新增、编辑、删除常用游客信息
- **默认游客设置**：设置默认出行人
- **游客信息查询**：根据用户ID查询常用游客信息
- **游客信息导入**：支持批量导入游客信息

### 8. 分销商管理
- **分销商审核**：管理员审核分销商申请
- **分销商等级管理**：根据分销商等级计算佣金
- **佣金计算**：根据订单金额计算分销商佣金
- **佣金查询**：分销商查询自己的佣金记录
- **佣金统计**：统计分销商佣金收入

### 9. 数据分析与报表
- **数据统计**：景区访问量、销售额、订单量等数据统计
- **图表展示**：使用ECharts实现数据可视化
- **报表导出**：支持将统计数据导出为Excel文件
- **数据预测**：根据历史数据预测未来销售趋势

### 10. 邮件通知模块
- **注册验证邮件**：用户注册时发送验证邮件
- **密码重置邮件**：用户忘记密码时发送重置邮件
- **订单通知邮件**：订单创建、支付、核销时发送通知邮件
- **系统通知邮件**：系统维护、异常等通知邮件

## 项目特色

### 1. 多角色支持
- 支持管理员、游客、分销商三种角色
- 不同角色有不同的权限和功能
- 分销商可以推广门票并获得佣金

### 2. 完整的购票流程
- 从景区查询、门票预订、支付到核销的完整流程
- 支持常用游客信息预填
- 提供电子门票和核销功能

### 3. 数据可视化
- 使用ECharts实现数据图表展示
- 提供景区访问量、销售额等数据分析
- 支持数据导出和报表生成

### 4. 安全与性能优化
- 使用JWT进行身份认证
- 实现权限控制和数据安全
- 使用Redis缓存提高性能
- 数据库优化和查询优化

### 5. 响应式设计
- 前端页面响应式设计
- 支持移动端访问
- 提供良好的用户体验

## 总结

票务管理系统是一个功能完整、架构清晰的票务分销平台。系统采用前后端分离架构，使用Spring Boot和Vue 3技术栈，支持多角色管理和完整的购票流程。通过合理的模块划分和团队分工，实现了高效的开发和维护。系统具有良好的扩展性和可维护性，可以满足不同场景的票务管理需求。
