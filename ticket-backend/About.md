# 🎟️ Ticket-Distribution: 基于 Java 21 的旅游门票分销管理系统

> **项目状态：** 开发中 (v0.0.1)
> **核心特性：** Java 21 LTS | Spring Boot 3 | MyBatis Plus | Redis 高并发 | 分销裂变

## 📖 项目简介 (Introduction)

本项目是一个服务于**景区、分销商（旅行社/代理）和游客**的 B2B2C 旅游门票分销平台。
系统解决了传统线下售票效率低、渠道管理混乱的问题，核心业务包含**票务管理、多级分销、库存并发控制、以及核销验票**。

本项目严格遵循**高内聚、低耦合**的设计原则，采用 **Java 21 + Spring Boot 3** 最新技术栈开发，旨在作为高分毕业设计项目，同时具备企业级开发的参考价值。

## 🏗️ 系统架构与模块划分 (Architecture)

项目采用简化的 **DDD (领域驱动设计)** 分层架构，目录结构如下：

```text
com.yourname.ticket
├── common          // [公共模块]
├── config          // [配置模块] Redis、MyBatis、Security、Swagger配置
├── controller      // [接口层] 处理HTTP请求，参数校验
├── entity          // [实体层]
│   ├── dto         // 数据传输对象 (接收前端参数，使用 Java record)
│   ├── vo          // 视图对象 (返回前端数据)
│   └── po          // 持久化对象 (对应数据库表)
├── service         // [业务层] 核心业务逻辑 (事务控制)
├── mapper          // [持久层] 数据访问接口
└── manager         // [通用逻辑层] (可选) 处理第三方支付、复杂聚合逻辑

```

## 💼 核心业务流程 (Business Logic)

### 1. 角色定义

* **平台管理员 (Admin):** 管理景区资源、审核分销商、查看财务报表。
* **分销商 (Distributor):** 申请分销资格、生成推广链接、查看佣金。
* **游客 (Tourist):** 浏览景点、购票支付、获取核销码。

### 2. 关键业务流

* **分销流程:** 管理员发布门票 (原价 100) -> 设置分销价 (80) -> 分销商生成链接 -> 游客购买 (100) -> **分销商赚取差价 (20)**。
* **高并发抢票:** 游客下单 -> **Redis 预减库存 (Lua脚本)** -> 发送消息队列 (可选) -> 异步扣减 MySQL 库存 -> 生成订单。
* **核销流程:** 游客出示二维码 -> 闸机/工作人员扫码 -> 请求后端 `verify` 接口 -> **校验状态与有效期** -> 修改订单状态为“已使用”。
